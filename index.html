Примерочная для пропусков

Автономная версия — работает как обычная веб-страница, без catwar.su и catwar.net. Открывайте файл в браузере или разместите его на любом хостинге.

Картинки берутся из папки img рядом с этим файлом. Файлы можно перетаскивать прямо из проводника на нужные места. Кнопка «+» на модельке создаёт её копию.

Скачать все картинки

Соберёт все картинки мода в один ZIP-архив, разложенные по папкам: «Аксессуары» (по типу детали), «Модели» (по группе) и «Конструктор» (база).

Сохранить костюмы с приставкой

Загрузите несколько PNG/JPG, впишите приставку — получите ZIP с файлами вида имя_приставка.png.

Перетащите файлы сюда или выберите вручную

    Локальный инструмент примерки. Картинки берутся из папки img этого репозитория.
